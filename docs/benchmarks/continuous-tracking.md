# 连续运动闭环对照（2026-09-11）

本轮比较对象是修改前后的同一生产控制器。录像仅提供运动形态参考，以下数字不是从用户视频测出的，也不证明实机优于参考视频。

## 统一条件

- 摄像/检测 120Hz，控制输出 120Hz；独立的采样、到达、执行时间。
- 测量延迟 16ms，发送后执行延迟 5ms，实际及标定倍率均为 1 像素/计数。
- 每轴加入最大 0.2px 的确定性小噪声；每 120 帧漏掉一帧。观测方差下限为 1，与生产基础观测设置一致。
- 仿真步长 0.5ms。先运行 1 秒，再统计 **1.0–1.5 秒的运动发生过程**，包含机动开始的瞬态，不截取停稳后的尾段。
- 实际场景位置由独立的物理执行队列计算，不能用控制器自己的指令预测当作真值。
- 输出为直线模式，不包含摄像机、神经网络推理、固件或游戏执行。像素是模拟图像坐标，不能换算成实机响应保证。

## 结果

| 场景 | P95 误差 / px | 峰值误差 / px | 误差不超过 3px 的时间占比 |
| --- | --- | --- | --- |
| 匀速横移 | 2.60 → 1.50 | 3.15 → 1.75 | 99.3% → 100.0% |
| 连续变速 | 12.40 → 3.95 | 13.33 → 5.25 | 30.3% → 85.9% |
| 急停 | 12.00 → 6.00 | 12.00 → 8.00 | 76.7% → 85.0% |
| 突然反向 | 20.65 → 4.35 | 23.20 → 16.70 | 72.7% → 94.1% |
| 持续加速 | 6.58 → 3.75 | 7.74 → 5.95 | 49.0% → 87.0% |
| 抛物线上下运动 | 15.64 → 10.29 | 18.09 → 13.54 | 2.5% → 77.9% |
| 二维转向 | 11.94 → 3.74 | 12.49 → 4.35 | 6.6% → 74.9% |
| 静止 | 0.00 → 0.00 | 0.00 → 0.00 | 100.0% → 100.0% |
| 位置突跳 | 22.90 → 23.90 | 25.20 → 26.20 | 62.6% → 92.5% |

突然反向和位置突跳在观测到达前无法得到纠正，因此峰值仍然明显。此次收益主要是减少持续变速的滞后、减轻观察到突变之后的拖尾；不应把 P95 的降低说成每一瞬间都已经贴住锚点。

## 变化与反例

1. 观测器增加加速度状态，并使用 Joseph 形式更新协方差。静止运动在统计上不显著时不外推噪声。
2. 输出改为最小化指令生效区间中点的位置误差，同时约束其偏离预测运动趋势的幅度，避免整周期运动量预付造成的单侧偏差。
3. 大模型创新触发短时降阶；位置突跳不直接变成持续极端速度，避免一次偏移产生第二次大幅移动。
4. 发送时刻到真正生效时刻有不确定性。落在观测边界附近的自身指令提高运动估计的不确定性，防止被误学成目标加速。
5. 初版加速度方案在“执行延迟估计差 2ms + 发送失败 + 换向”组合下触发原有回归失败，峰值约 222px；加入动作时序不确定性处理后，通过原有 150px 上限。这个压力测试还包含初始 60×60px 偏差，其峰值不能与上表直接比较。

## 覆盖与限制

`continuous_tracking_test` 包含 9 种轨迹 × 13 组条件，共 117 个模拟工况。除主条件的动程误差预算外，还检查 60/120/240Hz 采样、不同输出时钟、较长测量延迟、噪声增大、标定倍率变化、20% 标定误差、实际执行时间早/晚 2ms、2.5 倍运动速度下的有限性和峰值边界。压力条件不是全部满足 3px 的承诺。

完整原始结果见 `continuous-tracking-before.csv`、`continuous-tracking-after.csv`、`continuous-tracking-matrix.csv`；参数排列保存在 `continuous-tracking-configs.json`：输出 Hz、测量 ms、真实倍率、摄像 Hz、噪声幅度、抖动开关、模型倍率、执行时差 ms、速度倍率。

## 复现

```sh
cmake -S . -B build/logic-tests -DAPOTHEOSIS_LOGIC_TESTS_ONLY=ON
cmake --build build/logic-tests --config Release
ctest --test-dir build/logic-tests -C Release --output-on-failure
cmake --build build/logic-tests --config Release --target continuous_tracking_bench continuous_tracking_baseline
```

单配置生成器运行 `build/logic-tests/tests/continuous_tracking_bench` 和 `continuous_tracking_baseline`；VS 多配置生成器位于 `tests/Release/`，带 `.exe` 后缀。无参输出主条件 CSV；可选位置参数顺序同上。
